\# 🏥 Clínica da Aprendizagem - Front-end



Repositório do sistema corporativo de gestão da Clínica da Aprendizagem.



\## 🛠️ Stack Tecnológico



\* \*\*Framework:\*\* React 18 (Inicializado com Vite para build rápido)

\* \*\*Linguagem:\*\* TypeScript

\* \*\*Estilização:\*\* Tailwind CSS v4

\* \*\*UI/Componentes:\*\* Shadcn UI (Baseado em Radix UI)

\* \*\*Roteamento:\*\* React Router DOM

\* \*\*Tipografia e Ícones:\*\* Geist Font e Lucide React



\## 📂 Arquitetura Base



\*\*Feature-Driven Design (FDD)\*\*.

## 🚀 Como rodar o projeto localmente

1 - Instale as dependências:



npm install



2 - Inicie o servidor de desenvolvimento:



npm run dev
